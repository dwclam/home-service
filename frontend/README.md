# Nestify Frontend

Giao diện React + Vite của dự án Nestify. Xem [README dự án](../README.md) để cấu hình và chạy cả frontend lẫn backend.

```bash
npm ci
npm run dev
```

Các lệnh khác: `npm run lint`, `npm run build`, `npm run preview`.

Trang chủ nằm trong `src/App.jsx`, các section trong `src/components/`, dữ liệu mẫu trong `src/data/home.js`. Giao diện hiện chưa kết nối backend.
